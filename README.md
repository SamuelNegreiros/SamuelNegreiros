# 💻 Samuel Negreiros

**`Cientista de Dados`**

Olá! Me chamo Samuel Negreiros Ferreira, Sou formado em Análise e Desenvolvimento de Sistemas pela UNIP e atualmente estou direcionando minha carreira para a área de Ciência de Dados.

Estou desenvolvendo minhas habilidades em Python, SQL, Power BI, análise de dados e Machine Learning, com foco em transformar dados em informações e soluções que apoiem a tomada de decisões.

Em constante aprendizado, desenvolvendo projetos e construindo minha jornada na área de Dados.
